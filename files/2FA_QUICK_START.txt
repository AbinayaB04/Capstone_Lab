🔧 STEP 1: GMAIL SETUP (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

Goal: Create a Gmail "App Password" for your StudyMate AI app

ACTION 1: Enable 2-Step Verification
   1. Open: https://myaccount.google.com
   2. Click: Security (left sidebar)
   3. Find: "2-Step Verification"
   4. Click: Enable
   5. Follow the prompts

ACTION 2: Get App Password
   1. Open: https://myaccount.google.com/apppasswords
   2. If "App passwords" not showing, do Step ACTION 1 first
   3. Select: "Mail" and "Windows/Linux"
   4. Click: Generate
   5. Copy the 16-character password (with spaces)
   
Example: xxxx xxxx xxxx xxxx

ACTION 3: Update Your .env File
   
   Open: .env
   
   Add these lines:
   
   # Email Configuration for 2FA
   EMAIL_SENDER=your_gmail_email@gmail.com
   EMAIL_PASSWORD=xxxx xxxx xxxx xxxx   # Paste here!
   EMAIL_SMTP_SERVER=smtp.gmail.com
   EMAIL_SMTP_PORT=587
   
   # OTP Settings
   OTP_EXPIRY_MINUTES=5
   OTP_LENGTH=6

✅ Gmail Setup Done!

❓ COMMON QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q: Do I need to pay anything?
A: NO! Email OTP is completely FREE.

Q: What if users don't have email?
A: Update MongoDB to require email at registration.
   Or switch to SMS OTP (costs ~$1/month).

Q: Is this secure?
A: YES! Email OTP with 5-min expiry is good security.
   OTP codes are stored in Redis (in-memory, not on disk).

Q: Can I use SMS instead?
A: YES! See 2FA_OTP_EASY_SETUP.md for SMS OTP with Twilio.
   (Requires paid Twilio account - ~$1/month)

Q: What if user loses access to email?
A: Add backup codes (see advanced section in main guide).

Q: Can users bypass 2FA?
A: NO! It's required for all logins.


📞 QUICK TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ "No module named 'redis'"
   → Run: pip install redis

❌ "Redis connection refused"
   → Run: redis-server in another terminal

❌ "Email not received"
   → Check spam folder
   → Check Gmail app password in .env
   → Regenerate app password

❌ "OTP expired"
   → Default is 5 minutes
   → Change: OTP_EXPIRY_MINUTES=10 in .env

❌ "SMTP error"
   → Check EMAIL_SMTP_SERVER=smtp.gmail.com (capital letters matter)
   → Check EMAIL_SMTP_PORT=587
